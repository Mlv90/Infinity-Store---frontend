# Infinity Storys - Frontend

Infinity Store, loja interativa desenvolvida com HTML, CSS e JavaScript puro.
Possui fundo animado com efeitos visuais, transições suaves entre os produtos e
funciona tanto no modo automático quanto manual. Totalmente responsivo e com
navegação por teclado.

🔗 [Veja online aqui](https://mlv90.github.io/Infinity-Store---frontend/)

## Recursos
- Fundo com círculos pulsando
- Carrossel automático e manual
- Suporte para teclado (setas ← →)
